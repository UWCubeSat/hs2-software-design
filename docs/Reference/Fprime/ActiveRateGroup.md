# Svc::ActiveRateGroup

## Overview

`Svc::ActiveRateGroup` is an F' active component that receives a rate-group signal and invokes a configured list of components at that rate.

## HuskySat-2 Use

Active rate groups schedule periodic application and manager work while preserving the component interfaces used in GDS and flight deployments. The final topology will assign components to rates based on control-loop, telemetry, and housekeeping needs.
