# Svc::FprimeDeframer

## Overview

`Svc::FprimeDeframer` is an F' passive component that removes native F' framing from received packets and forwards the decoded payload.

## HuskySat-2 Use

It is available on the uplink path when the configured ground interface uses native F' framing before command dispatch.
