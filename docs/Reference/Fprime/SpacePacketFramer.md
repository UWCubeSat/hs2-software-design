# Svc::Ccsds::SpacePacketFramer

## Overview

`Svc::Ccsds::SpacePacketFramer` is an F' passive component that constructs CCSDS space packets from outgoing F' packet data.

## HuskySat-2 Use

It prepares telemetry, event, and other downlink data for the CCSDS telemetry-frame path used by the S-band communications subsystem.
