# Svc::FileUplink

## Overview

`Svc::FileUplink` is an F' active component that receives file-transfer packets and reconstructs files in the onboard filesystem.

## HuskySat-2 Use

It supports ground-to-space delivery of configuration, parameter, and operational files through the communications and file-management paths.
