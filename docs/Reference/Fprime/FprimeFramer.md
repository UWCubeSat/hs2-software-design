# Svc::FprimeFramer

## Overview

`Svc::FprimeFramer` is an F' passive component that wraps outgoing packets in the native F' framing format.

## HuskySat-2 Use

It is available to the communications topology where native F' framing is required before packets reach the radio byte-stream interface.
