# DpCatalog

## Overview

`DpCatalog` is an F' active component that catalogs stored data products and manages their availability for later operations such as downlink.

## HuskySat-2 Use

It gives the science-data pipeline a searchable record of stored products and supports the eventual retention and downlink policy.
