# Svc::PrmDb

## Overview

`Svc::PrmDb` is an F' active component that stores and retrieves persistent component parameters.

## HuskySat-2 Use

It provides the parameter persistence path used to retain configured values across deployments and reboot cycles, subject to the final storage and recovery design.
