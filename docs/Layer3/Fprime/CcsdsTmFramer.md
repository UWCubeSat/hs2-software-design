# Ccsds::TmFramer

## Overview

`Ccsds::TmFramer` is an F' passive component that formats outgoing telemetry and event packets into CCSDS telemetry frames.

## HuskySat-2 Use

It provides the CCSDS telemetry-frame boundary used by the S-band downlink path after packet aggregation and before transmission through the radio interface.
