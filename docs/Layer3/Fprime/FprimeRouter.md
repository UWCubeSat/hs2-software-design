# FprimeRouter

## Overview

`FprimeRouter` is an F' passive component that routes decoded packets to the appropriate command, telemetry, or event destination.

## HuskySat-2 Use

It connects the communications receive path to `CmdDispatcher` and other packet consumers after uplink frames have been deframed.
