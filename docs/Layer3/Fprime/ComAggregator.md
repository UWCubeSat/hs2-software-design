# ComAggregator

## Overview

`ComAggregator` is an F' passive component that combines outgoing packet streams before they enter the configured communications framing path.

## HuskySat-2 Use

It allows telemetry, events, and other downlink packet sources to share the CCSDS framing and radio interface while preserving packet boundaries.
